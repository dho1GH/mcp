1 — health + list tools

curl -X POST http://localhost:8787/mcp \
  -H "Authorization: Bearer $MCP_AUTH_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
2 — read: list lights (no grant) 
curl -X POST http://localhost:8787/mcp \
  -H "Authorization: Bearer $MCP_AUTH_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc":"2.0","id":2,"method":"tools/call",
    "params":{"name":"hue_list_lights","arguments":{}}
  }'
3 — write: rename light (grant should ALLOW)
Match allowedTargets to the light's real current name first.
curl -X POST http://localhost:8787/mcp \
  -H "Authorization: Bearer $MCP_AUTH_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc":"2.0","id":3,"method":"tools/call",
    "params":{
      "name":"hue_rename_light",
      "arguments":{
        "lightKey":"Beta Bedroom",
        "newName":"Beta Bedroom Lamp",
        "grant":{
          "grantId":"test-001",
          "scope":"APPLY_HUE_METADATA_ONLY",
          "systems":["hue"],
          "allowedOperations":["metadata_write"],
          "allowedTargets":["Beta Bedroom"],
          "forbiddenSystems":["home_assistant","node_red"],
          "forbiddenOperations":["restart","reload","delete","deploy"],
          "expires":"after_single_execution",
          "postAuditRequired":true
        }
      }
    }
  }'
4 — write: rename light (grant should BLOCK — wrong target)
